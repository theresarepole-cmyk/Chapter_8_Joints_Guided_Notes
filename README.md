# Chapter 8 – Joints Interactive Guided Notes

GitHub Pages website for student guided notes.

## Upload
1. Create a public GitHub repository named `Chapter_8_Joints_Guided_Notes`.
2. Upload `index.html`, `README.md`, and the **entire `media` folder** at the repository root.
3. Go to Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Features
Editable guided-note blanks and the seven source tables; note highlighting; autosave; progress and unanswered checks; optional student-supplied diagram images; editable labels, colors, backgrounds, arrows, pen, undo, redo, delete, per-picture clear, enlarged diagram workspace; JSON backup; PDF and Google Docs HTML export.

The original Google Doc includes three floating diagrams (synovial joint anatomy, joint movements part 1, and joint movements part 2); all three are included in the `media` folder and shown in the relevant sections. Two extra blank diagram workspaces remain optional. Photos uploaded into workspaces are compressed and stored locally in the browser; if browser storage fills, download a backup promptly.

This site is static, with no student submissions sent to a server.

## Required diagrams
Upload the `media` directory with `image1.png`, `image2.png`, and `image3.png` alongside `index.html`.
